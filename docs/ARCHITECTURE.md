# Как устроена система

Проверенная конфигурация: Станция Макс, Android 9, сборка `20221212`. Штатный `maind` остаётся владельцем микрофонов, слова активации, динамиков, таймера и LED-устройств. Наши приложения подключают локальные службы и исполняют команды.

## Что выполняет Станция

| Слой | Компонент | Работа |
| --- | --- | --- |
| Управление | Station Agent | Bluetooth RFCOMM, команды пульта, расписания, веб-панель |
| Голос | Voicebridge | Приём штатного голосового потока, декодирование, локальный Sherpa ASR, разбор команд |
| Ответы | Voicebridge → разрешённые API | Запрос GigaChat, потоковая озвучка Speechify, доставка ответа штатному клиенту |
| Музыка | Локальная служба + штатный плеер | Каталог, поиск, кеш и HTTP Range; воспроизведение и LED-визуализация |
| Конфигурация | LocalServices | TLS config, OTA-ответ без обновления, push и применение настроек дисплея |
| ТВ | CleanYourTV | Главный экран, приложения, темы |

Активация «Алиса» остаётся штатной. ASR выполняется на колонке, сложные ответы и синтез речи — во внешних облаках. Ввод таймера и его остановка распознаются и исполняются локально; подтверждение голосом может обращаться к TTS.

Телефон не обрабатывает речь и не является сетевым шлюзом. Пульт использует Bluetooth HID для клавиш и RFCOMM для функций Agent. Приложение телефона не запрашивает разрешение `INTERNET`.

## Зачем нужен Windows

ПК предоставляет ограниченный CONNECT-туннель к разрешённым API/CDN, USB/Ethernet-сеть, ADB forward/reverse, контроль OTA и восстановление соединений. Веб-порт ПК пересылает запросы интерфейсу Agent на колонке. В текущем режиме ПК не распознаёт речь, не формирует ответы и не хранит активный музыкальный каталог.

**Это ещё не автономная колонка:** при выключенном ПК пропадёт необходимый сетевой транспорт. Прямой Wi-Fi с произвольным интернет-доступом не входит в проверенную схему. Системный `http_proxy` не покрывает native Quasar; экспериментальный VPN отключён после потери управления устройством.

Отдельная ограниченная VPN-проба уже захватила контрольный трафик и TCP-сокеты UID0 к порту 443 с проверенным откатом. Это исследование охвата, а не постоянная защита OTA. [Результаты и условия автономного Wi-Fi](research/wifi-autonomy.md).

## Локальные службы

| Порт на Станции | Назначение |
| --- | --- |
| `18080` | Agent, веб-панель и локальное API |
| `17682` | Голосовой WebSocket |
| `17683` | TLS config/OTA |
| `17684` | Native config push |
| `17685` | HTTP config и проверки сети |
| `17686` | Музыкальный каталог и аудио |
| `18443` | ADB reverse к CONNECT-туннелю ПК |

Порты и адреса — часть этой развёртки, а не универсальные значения прошивки. Установочный профиль задаёт их явно. Туннель пропускает только имена из allowlist; неизвестные назначения отклоняются. Сертификат локального config должен приниматься именно штатным клиентом, а не только браузером или `curl`.

## Дисплей и кольцо

Настройки переднего экрана передаются локальной config-службе, push уведомляет native-клиент, затем проверяется чтение нового состояния. Статус «Применено» не подменяется фактом отправки запроса. В проверенной сети размер часов менялся за 0,1–2 с; это замер конкретной установки.

Верхнее кольцо — отдельное устройство. Подробности и границы доступа: [RING.md](RING.md).

## Секреты и восстановление

Публичные исходники отделены от приватного профиля. API-ключи, TLS-ключи, данные аккаунта и ключи подписи в репозиторий не входят. Зашифрованная резервная копия хранится отдельно. [SETUP.md](SETUP.md) описывает развёртывание, [REPRODUCIBILITY.md](REPRODUCIBILITY.md) — что можно воспроизвести и какие предварительные условия нужны.
