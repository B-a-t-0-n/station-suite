# Как устроена система

Проверенная конфигурация: Станция Макс, Android 9, сборка `20221212`. После сообщения пользователя об обновлении выполнены factory reset, официальная проводная настройка и восстановление приложений Suite. ADB снова доступен, Android build/fingerprint и хеш штатного `maind` совпали с сохранёнными до сброса. Установка новой ОС/native-прошивки не подтверждена; возможные обновления APK до сброса теперь не установить. После восстановления пользователь подтвердил новый голос, музыку и паузу из Bluetooth-пульта. Ниже описан восстановленный рабочий стек. Штатный `maind` владеет микрофонами, словом активации, динамиками, таймером и LED-устройствами; наши приложения подключают локальные службы и исполняют команды.

## Что выполняет Станция

| Слой | Компонент | Работа |
| --- | --- | --- |
| Управление | Station Agent | Bluetooth RFCOMM, команды пульта, расписания, веб-панель |
| Голос | Voicebridge | Приём штатного голосового потока, декодирование, локальный Sherpa ASR, разбор команд |
| Ответы | Voicebridge → разрешённые API | Запрос GigaChat, потоковая озвучка Speechify, доставка ответа штатному клиенту |
| Музыка | Локальная служба + штатный плеер | Каталог, поиск, кеш и HTTP Range; воспроизведение и LED-визуализация |
| Конфигурация | LocalServices | TLS config, OTA-ответ без обновления, push и применение настроек дисплея |
| ТВ | CleanYourTV | Главный экран, приложения, темы |

Активация «Алиса» остаётся штатной. ASR выполняется на колонке, сложные ответы и синтез речи — во внешних облаках. Ввод таймера и его остановка распознаются и исполняются локально; подтверждение голосом может обращаться к TTS.

Телефон не обрабатывает речь и не является сетевым шлюзом. Пульт использует Bluetooth HID для клавиш и RFCOMM для функций Agent. Приложение телефона не запрашивает разрешение `INTERNET`.

## Сетевые режимы и роль Windows

В основной проводной схеме ПК предоставляет ограниченный CONNECT-туннель к разрешённым API/CDN, USB/Ethernet-сеть, ADB forward/reverse, контроль OTA и восстановление соединений. Веб-порт ПК пересылает запросы интерфейсу Agent на колонке. ПК не распознаёт речь, не формирует ответы и не хранит активный музыкальный каталог.

Отдельный [экспериментальный Wi-Fi-модуль](../experimental/wifi-standalone/README.md) направляет известные служебные имена на виртуальный адрес и через два IPv4 `/32` доставляет запросы в loopback config/push/HTTP-службы. Остальной интернет идёт напрямую через домашний Wi-Fi. Voicebridge выбирает Wi-Fi для своего процесса; облачные API используют `lab_proxy_port: 0`, музыка — явный `transport: "direct"`.

18 ноября Wi-Fi с 14 адресными запретами на домашнем роутере проверен после программной перезагрузки без Ethernet и PC business services. Локальные службы, голос, split VPN и системное NTP-время запустились автоматически; пользователь подтвердил новый голос и музыку. Запреты и обычный HTTPS проверены повторно после загрузки. [Конфигурация и пределы результата](research/ordinary-wifi-known-deny.md). Телефонные стрелки используют Bluetooth HID без shell helper; отдельный shell input helper для веб-навигации не имеет подтверждённого автономного boot.

**Прямой Wi-Fi не гарантирует блокировку OTA.** Ранее доказан системный обход обычного VPN; DNS-подмена и локальный ответ без обновления не закрывают все native/root-пути. Старый VPN coverage PoC после потери управления отключён; новый модуль имеет отдельный процесс, ограниченные тестовые запуски и остановку. Always-on и lockdown не включаются. [История проверок и границы результата](research/wifi-autonomy.md).

В проводном режиме ПК теперь повторно проверяет выключенное состояние Wi-Fi и
отсутствие IPv4/global IPv6 на `wlan0`. При обнаруженном включении закрывает
локальную relay lease, выключает Wi-Fi и проверяет результат. При неизвестном
состоянии lease закрывается, tunnel supervisor не выдаёт READY. Проверка выполняется в цикле
supervisor с паузой 2 секунды и ограниченными по времени ADB-командами; это
реактивный контроль с окном между проверками. Он не работает без ПК/ADB и не
обеспечивает запрет исходящего трафика во время ранней загрузки Станции.
[Причина доработки и результаты](research/wired-wifi-guard.md).

## Локальные службы

| Порт на Станции | Назначение |
| --- | --- |
| `18080` | Agent, веб-панель и локальное API |
| `17682` | Голосовой WebSocket |
| `17683` | TLS config/OTA |
| `17684` | Native config push |
| `17685` | HTTP config и проверки сети |
| `17686` | Музыкальный каталог и аудио |
| `18443` | ADB reverse к CONNECT-туннелю ПК |
| `17694` | Loopback SOCKS экспериментального Wi-Fi-модуля |

В веб-панели Agent 0.7.6 вкладка «Состояние» показывает загрузку процессора, доступную ОЗУ, место в разделе данных и время работы. Agent отдаёт значения через `GET /api/hardware`. История за две минуты хранится в открытой вкладке браузера и обновляется раз в три секунды. На проверенной Станции Макс Android закрывает системный счётчик CPU и датчик температуры. В этом случае панель оценивает общую загрузку по счётчикам простоя ядер и помечает температуру как недоступную.

Порты и адреса — часть этой развёртки, а не универсальные значения прошивки. Установочный профиль задаёт их явно. В проводной схеме туннель пропускает только имена из allowlist; неизвестные назначения отклоняются. В экспериментальном direct-режиме такого общего интернет-фильтра нет. Сертификат локального config должен приниматься именно штатным клиентом, а не только браузером или `curl`.

## Дисплей и кольцо

Настройки переднего экрана передаются локальной config-службе, push уведомляет native-клиент, затем проверяется чтение нового состояния. Статус «Применено» не подменяется фактом отправки запроса. В проверенной сети размер часов менялся за 0,1–2 с; это замер конкретной установки.

Верхнее кольцо — отдельное устройство. Подробности и границы доступа: [RING.md](RING.md).

## Секреты и восстановление

Публичные исходники отделены от приватного профиля. API-ключи, TLS-ключи, данные аккаунта и ключи подписи в репозиторий не входят. Зашифрованная резервная копия хранится отдельно. [SETUP.md](SETUP.md) описывает развёртывание, [REPRODUCIBILITY.md](REPRODUCIBILITY.md) — что можно воспроизвести и какие предварительные условия нужны.
