# Station Suite 0.8.0

Первый публичный снимок текущей системы. [Скачать выпуск](https://github.com/B-a-t-0-n/station-suite/releases/tag/v0.8.0).

| Файл | Назначение |
| --- | --- |
| `station-remote-0.8.0.apk` | Bluetooth-пульт телефона: все страницы и редакторы в едином светлом стиле |
| `station-agent-0.7.4.apk` | Приложение Станции: команды, музыка, расписания, веб-панель; удалён старый встроенный TLS proxy |
| `station-voice-bridge-0.21.apk` | Голос и локальные config/push/music-службы; модель ASR скачивается отдельно |
| `cleanyourtv-theme-gallery.apk` | Проверенная версия лаунчера 3.4 из закреплённого пользовательского форка |
| `cleanyourtv-offline-themes.zip` | 29 тем с обоями, превью и credits |
| `cleanyourtv-licenses.txt` | Лицензии лаунчера, шрифта и иконок |
| `station-suite-windows-0.8.0.zip` | Инструменты Windows, установочные/сборочные скрипты, шаблоны и документация |
| `SHA256SUMS.txt` | Контрольные суммы файлов выпуска |

Исходники Android-приложений находятся в Git и в автоматически создаваемых GitHub Source code archives. Закрытых конфигов, API-ключей, TLS-ключей, signer и сторонних ТВ-APK в выпуске нет.

## Что проверено

- Телефон 0.8 установлен; просмотрены все десять страниц, выбор устройства, редакторы таймера и будильника. 17 снимков переходов, команды Станции не отправлялись, редакторы не сохранялись.
- Сборки всех трёх собственных APK прошли проверку подписи, выравнивания и manifest. Все ZIP payload entries переносимых сборок телефона и Voicebridge совпали с установленными сборками.
- Agent 0.7.4 установлен поверх существующего приложения. Старый приватный TLS asset и его реализация удалены.
- После обновления read-only проверка подтвердила локальный TLS, отсутствие OTA, локальные voice/push endpoints и доступность настроек дисплея.
- Зашифрованная копия 11 приватных файлов создана вне Git и успешно расшифрована для проверки; тесты проверяют неверный пароль, повреждение архива, недопустимые пути и отсутствие изменений при dry run.
- Перед публикацией проверены исходники и содержимое APK; выполнены gitleaks и поиск совпадений с реальными приватными данными этой установки.
- Лаунчер пересобран из закреплённого коммита: 322 теста, lint без ошибок; ресурсы APK и 217 файлов пакета тем совпали. [Подробности](LAUNCHER.md).

## Границы выпуска

ПК остаётся необходимым сетевым транспортом. Ручное управление верхним кольцом и RGB под музыку не реализовано: [результаты исследования](RING.md). Передний дисплей, его музыкальные анимации и штатная индикация таймеров работают отдельными путями.

Переносимые Windows-обёртки проверены тестами, но полный запуск на другом чистом ПК и factory-reset устройстве не проводился. Для восстановления нужны предварительно подготовленная совместимая Станция и собственные приватные данные. [Установка](SETUP.md) · [Границы воспроизводимости](REPRODUCIBILITY.md).
