# Station Suite 0.8.1

Выпуск возвращает рабочую проводную конфигурацию после factory reset совместимой
Станции Макс и добавляет подготовленный сценарий повторного восстановления.

| Компонент | Версия |
| --- | --- |
| Пульт Android | 0.8.0 |
| Station Agent | 0.7.5 |
| Voicebridge | 0.22 |
| CleanYourTV | 3.4, отдельный закреплённый форк |
| Офлайн-темы | 29 |

`tools/Restore-Station.ps1` проверяет приватные входные файлы и выбранное
устройство. С `-Apply` он устанавливает приложения, модель и собственную
конфигурацию, возвращает оформление и Home, затем запускает PC-транспорт.
Готовые личные параметры остаются вне Git. Полный порядок:
[восстановление](RECOVERY.md).

Установка модели поддерживает пустую папку нового приложения. Бинарные файлы
модели передаются через `adb push`, приватный TLS-контейнер — через ASCII base64
в закрытый staging приложения. Перед заменой проверяются SHA-256.

PC-транспорт имеет одного владельца, проверку OTA-ответчика, запуск без
дублирования процессов и отдельный режим для уже работающего DHCP. ПК не
обрабатывает голос, ответы и музыкальный каталог.

Voicebridge 0.22 используется с туннелем. Экспериментальный прямой Wi-Fi
не включается восстановителем; этот выпуск не подтверждает защиту от OTA
при прямом подключении к интернету.

Проверены 140 профильных тестов и полный запуск восстановления на той же
Станции после сброса: 9 групп приложений, 4 файла модели, 7 приватных файлов,
232 файла лаунчера. PC owner и локальные службы перешли в `ready`, дисплей —
в `applied`, локальный OTA-ответчик вернул `hasUpdate:false`. Пользователь
подтвердил новый голос, запуск песни голосом и паузу с Bluetooth-пульта.
Это проверка текущего проводного сеанса; повторный
холодный старт TCP ADB и чистая установка на другом ПК не подтверждены.

APK и контрольные суммы доступны в [Releases](https://github.com/B-a-t-0-n/station-suite/releases/tag/v0.8.1).
Сторонние ТВ-приложения и личные данные в выпуск не включены. Их установка
возможна по собственным локальным APK, явно указанным в recovery-профиле.
