# Спектр штатного плеера Макс

16 ноября 2026 года отдельный диагностический APK подтвердил получение спектра
штатного музыкального плеера на Станции Макс `yandexstation_2`, Android 9,
прошивка `20221212`, Agent `0.7.4`. Native Quasar и плеер сохранены.

Это проверка конкретного звукового пути на нашей прошивке. Она не доказывает
покрытие всех ТВ-приложений, HDMI, offload-режимов или других прошивок.

## Что проверяли

Диагностический модуль [`music-spectrum`](../../experimental/music-spectrum/)
версии `0.1` подключается к Android `Visualizer` с audio session `0` — общему
выходному миксу. В этой проверке зафиксированы:

| Параметр | Значение |
| --- | --- |
| Размер FFT | 1024 |
| Частота callback | 10 Гц |
| Частота дискретизации | 44 100 Гц |
| Масштабирование | `SCALING_MODE_AS_PLAYED` |
| Агрегация | 24 логарифмические полосы от 50 до 16 000 Гц |
| Окно каждого запуска | 30 секунд |

Размер и расположение FFT-компонентов, права и поведение общего микса описаны
в [официальном Android API Visualizer](https://developer.android.com/reference/android/media/audiofx/Visualizer).
Наш код сразу сворачивает callback в числовые агрегаты. Значения относительные,
не калиброванные децибелы и не измерение мощности полос.

## Результаты на устройстве

| Состояние | Получено кадров | Кадров с ненулевым спектром | Максимальная относительная величина |
| --- | ---: | ---: | ---: |
| Простой, первый запуск | 296 | 0 | 0 |
| Штатная музыка, первый запуск | 296 | 296 | 0.0234375 |
| Пауза, первый запуск | 296 | 175 | Не используется для итогового вывода |
| Пауза, повторный запуск | 296 | 0 | 0 |
| Штатная музыка, повторный основной замер | 296 | 296 | 0.024705294220065465 |

Во время музыкальной проверки пользователь подтвердил, что трек слышен.
Первый запуск после паузы оказался загрязнён: с восьмой секунды снова
наблюдались ненулевые кадры, их источник не установлен. Для этого прогона
нет независимого timeline воспроизведения, поэтому он не представлен
как чистый контроль тишины. В повторной проверке паузы все кадры были нулевыми;
отдельная обезличенная проверка статуса раз в секунду подтверждала
`playing=false`, состояние паузы и позицию `0`.

Повторный музыкальный замер также дал ненулевой спектр во всех 296 кадрах.
На всём протяжении независимого timeline подтверждены `playing=true` и
штатное состояние воспроизведения; в timeline позиция изменилась с 417 до
30 374 мс, финальный контрольный снимок показал 30 465 мс. После окна
подтверждены освобождение Visualizer и отсутствие процесса
диагностического пакета. Режимы `voice` и `control` не запускались: уже получен
повторяемый положительный результат на реальной штатной музыке.

Обезличенные агрегаты пяти прогонов с пометками принятых и исключённого
контроля: [device-20221212.json](../../experimental/music-spectrum/results/device-20221212.json).

## Что этот результат позволяет

У нас появился подтверждённый источник цифровых музыкальных данных без
подмены штатного плеера и без отдельного микрофонного захвата. Его можно
использовать как основу будущего эффекта кольца после решения аппаратного
управления и приоритетов.

Session `0` содержит общий выходной звук: ответы ассистента и системные сигналы
тоже могут дать спектр. Для музыкального режима недостаточно проверять
ненулевой FFT — нужна привязка к подтверждённому `native playing` и отдельная
обработка паузы. Спектр сам по себе не сообщает название или источник звука.

## Ограничения и воспроизводимость

- APK не имеет `INTERNET`, не использует `AudioRecord`, не сохраняет микрофон,
  PCM, waveform или сырые FFT-кадры. Только ограниченные числовые отчёты.
- Android требует runtime-разрешение `RECORD_AUDIO` для подключения Visualizer
  к общему миксу. Это требование API, а не наличие записи микрофона в модуле.
- Каждый запуск ограничен отдельным watchdog по elapsed time; после завершения
  проверены флаги освобождения созданных ресурсов. В независимом `finally`
  диагностический пакет принудительно останавливался после каждого прогона.
- Убийство приложения не является гарантией отмены зависшего native-вызова;
  постоянная интеграция требует отдельной проверки жизненного цикла и прав.
- SHA256 проверенного APK `station-spectrum-probe-0.1.apk`:
  `ad61fc308862f2486c9c7a26fb93b00652d57b360d6757c07788d3c9058a2c1a`.
- Реализация написана самостоятельно. Код и ассеты OPENSTATION не копировались;
  проект послужил указанием на архитектурную возможность Visualizer session `0`.
- 13 host-тестов проверяют фактическую Java-арифметику полос; они не заменяют
  перечисленные выше аппаратные проверки.

В постоянном приложении ещё необходимо выбрать, как выдаётся и проверяется
разрешение, как модуль запускается и освобождается и как обрабатывается отказ
audio effect. Доступ к RGB-кольцу и совместное владение им остаются отдельной
задачей: голос, отключённые микрофоны, таймер и ошибки должны иметь приоритет.

Следующий этап — узкий backend кольца поверх уже исследованных интерфейсов,
с ограниченным набором команд и подтверждением состояния. Полная замена
прошивки или запуск второго бесконечного framebuffer-renderer для этого
результата не требуются.
