# Голосовой поиск на телевизоре

На Станции Макс с Voicebridge 0.23 работают такие команды.

- «Алиса, включи мне фильм Простоквашино». Станция проверит установленные видеоприложения и откроет подходящую карточку.
- «Алиса, найди мне на Окко Простоквашино». Станция ограничит поиск Окко. Если карточку не удастся подтвердить, откроется раздел поиска в Окко.
- «Алиса, открой VK Видео» или «Алиса, какие приложения установлены на телевизоре».

Станция распознаёт речь локально. GigaChat уточняет написание названия, например исправляет «простаквашено». Ограничение по приложению, типу и году определяется из команды. В интернет-поиск передаются название и эти ограничения. Станция обращается к публичному поиску и каталогу напрямую по Wi-Fi. Для этого используется уже настроенный GigaChat.

Проверка установленных ТВ-приложений охватывает Окко, VK Видео, RUTUBE, YouTube и Lampa. Для первых четырёх Станция ищет карточки в сети. Lampa открывается голосом и принимает запрос в свой поиск, если установленная версия обрабатывает Android-команду поиска. Её результаты зависят от подключённых внутри неё источников.

Для Окко Станция сверяет название и адрес с официальной карточкой, затем берёт из неё ссылку Android. «Включи» передаёт приложению запрос воспроизведения, а «найди» открывает карточку. Доступ к фильму определяется самим видеосервисом с учётом аккаунта и региона. Для некоторых запросов поисковая выдача может дать неполные результаты.

На Станции Макс с Android 9 и сборкой 20221212 проверены две голосовые команды с «Простоквашино». Команда с указанием Окко открыла карточку фильма. Команда без названия сервиса выбрала Окко и открыла карточку или экран подписки. Начало воспроизведения в этом тесте не подтверждено.
