# Что воспроизводится

| Часть | Статус |
|---|---|
| Телефон, Agent, Voice Bridge | Полные собственные исходники, переносимые сборочные параметры и APK |
| Распознавание | Sherpa ONNX, фиксированная модель и четыре SHA-256; выполняется на Станции |
| PC tunnel/DNS/NTP/native relay | Исходники и переносимые запуск/установка, фиксированный список разрешённых внешних источников |
| DHCP | Конфиг и проверка SHA; официальный Tftpd64 загружается отдельно |
| Собственная конфигурация аккаунта/TLS | Только зашифрованная личная копия вне Git |
| Лаунчер | Отдельный форк с закреплённой ревизией; см. ссылки в README |
| Заводская разблокировка и сертификаты Quasar | Не включены; нужны совместимая прошивка, ADB и подготовленное доверие |
| Agent private prefs, Bluetooth pairing, Android settings | Повторная настройка после чистой установки |

Проверенная модель Станции и прошивка перечислены в [SETUP.md](SETUP.md). Репозиторий не содержит прошивку Яндекса, vendor binaries или чужие аккаунтные данные. Имеющийся обход OTA — свойства конкретного сетевого стенда и native config, а не универсальная блокировка обновлений на любой сети.

## Проверка публичного экспорта

Снимок содержит переносимые исходники Agent `0.7.5`, Voice `0.22`, телефона `0.8.0`. Собственные APK собираются существующим signer; подпись, alignment и manifest проверяются отдельно. Начиная с Agent `0.7.4` удалены прежняя пассивная реализация TLS proxy и встроенный приватный P12. Старые APK Agent, содержащие этот asset, не публикуются.

После factory reset этого устройства выполнено восстановление приложений, модели и приватных настроек; возвращены темы и Bluetooth-сопряжение. Переносимый PC-владелец запущен на том же ПК с уже настроенным изолированным Ethernet и внешним DHCP. Чистая установка на другом ПК не проверена. Новый bootstrap до появления ADB имеет offline-тесты; завершённая ручная проводная настройка выполнялась до его реализации. Сохранение TCP ADB после следующего холодного старта пока не подтверждено.

Сборка фиксирует SHA исходников и зависимостей, но побайтовая идентичность APK с другим JDK/SDK/signer не заявляется. Сертификат Android-подписи приватен. Восстановление из Releases не требует наличия signer; самостоятельное обновление установленного APK требует исходный signer либо отдельного плана переустановки с резервной копией данных.

## Отказоустойчивость и границы

При отсутствии native relay lease нет возврата к настоящим Yandex endpoints. PC-туннель не является общим SOCKS/HTTP proxy: соединения разрешаются по точному списку host/port, источник привязан к выбранному физическому WAN-интерфейсу. Без ПК голосовой runtime может оставаться запущен, но внешние API и сетевой транспорт недоступны. Заявлять полностью автономный режим с интернетом пока нельзя.

Нельзя включать общий NAT/ICS или переносить текущую схему в Wi-Fi без отдельного сетевого контроля: native Quasar обходит системный HTTP proxy, а безопасное покрытие VpnService в этой прошивке не доказано. Сброс к заводским настройкам не является способом устранения сетевого сбоя.
